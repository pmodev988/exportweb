# IT-001：从 LGA 分离独立网站

日期：2026-10-26。状态：实施中。

## 用户确认

新工程为 06ExportWeb，来源为最新 LGA。公司与目标市场纳入建站产品。独立站与 LGA 为两个单独购买的产品，会员增购享 95 折。宣传域名为 web.export.pmo.dev 与 ai.export.pmo.dev。

## 实施边界

1. 固定 LGA 来源提交，按依赖提取正式 Vue 编辑器与 Java 业务服务；不依赖 LGA 路径或运行进程。
2. 独立包名、配置、数据库、对象前缀、队列、OIDC 客户端和目录身份。保留原网站 ID、语言、版本和素材引用的迁移能力。
3. LGA 移除建站入口与写入能力，保留历史数据和现存公开站点的过渡读取，数字员工不因删表失效。
4. OPS 复用目录、域名、商务和支付能力；宣传网站跳转现有结算链路；优惠与建站权益由后端核验。
5. 独立构建、类型检查、权限及业务测试、数据迁移试验；按真实结果提交发布申请。

## 验收

可在没有 LGA 源目录的情况下构建；目标市场、建站编辑、版本、导出、发布能力可用；301 权益不能进入 302；跨组织读写被拒；保留支付验签与幂等；LGA 不能继续更改建站专属数据。

## 发布顺序与回退

OPS 目录与运行身份登记 → ExportWeb 本地验证 → 经核验的组织级数据及素材迁移 → 域名入口切换 → LGA 建站功能切离。发布由 RLS 执行。默认暂停并向前修复，不自动回退；如必须人工恢复旧应用或原域名路由，先核对切换后的写入，不删除任一侧数据、不回退数据库、不用旧快照覆盖新内容。
